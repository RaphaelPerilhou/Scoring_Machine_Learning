# Signaux Faibles — Corporate Default Scoring (Hotel & Restaurant Sector)

**Authors:** Victoria Godio, Baptiste Messant & Raphael Perilhou  
**Period covered:** 2017–2021  
**Sector:** Accommodation and food services (NAF codes 55.x / 56.x)

---

## Project overview

This project builds a credit-scoring pipeline that predicts corporate defaults for French hotel and restaurant companies. It replicates and extends the Banque de France methodology (Bardos, 2007) using three public data sources:

| Source | Description |
|--------|-------------|
| **BODACC** | Official gazette of civil and commercial announcements — used to identify default events (judicial proceedings) |
| **INPI** | Detailed company financial statements in nested Parquet format |
| **SIRENE** (`StockUniteLegale_utf8.csv`) | National business register — used to map SIREN identifiers to NAF sector codes |

Five models are compared on a held-out 2021 test set: LDA, Lasso (full), Lasso (ratios only), Decision Tree, and XGBoost.

## How to run

### Prerequisites

Install R (≥ 4.3) and Quarto, then install the required packages:

```r
install.packages(c(
  "tidyverse", "lubridate", "httr", "xml2", "archive",
  "purrr", "janitor", "stringr", "furrr", "curl",
  "stargazer", "arrow", "data.table",
  "FactoMineR", "factoextra", "rlang", "DescTools",
  "rpart", "rpart.plot", "glmnetUtils", "ROCR",
  "MASS", "caret", "xgboost", "pROC"
))
```

### Step 1 — Build the dataset

```bash
quarto render SF_DATA.qmd
```

This notebook:
1. Parses BODACC TAZ archives (already downloaded in `data/raw/BODACC_TAZ/`)
2. Merges with SIRENE/NAF
3. Filters and unnests the INPI financial data for the sector
4. Produces `data/processed/FINAL_DATABASE.parquet`

> The BODACC download loop is commented out in the notebook; raw TAZ files are expected in `data/raw/BODACC_TAZ/{year}/`. The INPI file (`data/raw/export-detail-bilan.parquet`) and the SIRENE file (`data/StockUniteLegale_utf8.csv`) must be obtained separately (see [Data sources](#data-sources)).

### Step 2 — EDA and modelling

```bash
quarto render SF_EDA_ANALYSIS.qmd
```

This notebook reads from `data/processed/` and produces:
- Exploratory plots (default rates, distributions, bivariate GLM fits)
- PCA and LDA analyses
- Lasso, Decision Tree, and XGBoost models with ROC/AUC comparisons

## Key design choices

- **Default labelling:** Following Bardos (2007), a default event is associated with the `date_cloture_exercice` closest to the first `date_jugement`. Observations after the first default are dropped for defaulting firms.
- **Default events classified:** *Jugement d'ouverture* of *redressement judiciaire*, *liquidation judiciaire*, *sauvegarde*, or *autre jugement d'ouverture*.
- **Missing value strategy:** Keep the 5% of non-defaulting firms with the fewest NAs across their history; drop variables with >25% NAs; impute remaining NAs with per-variable medians.
- **Winsorisation:** All numeric variables clipped to the 5th–95th percentile before modelling.
- **Train / validation / test split:** 2017–2019 / 2020 / 2021 (temporal split to avoid leakage).
